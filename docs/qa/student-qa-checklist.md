# 수강생(STUDENT) 전체 QA 체크리스트 — 페르소나 기반

> 목적: 한 명의 수강생 페르소나로 **수강생 포털 전체 화면**을 직접 클릭하며 기능·흐름·상태를 점검한다.
> 범위: 수강생 사이드바 노출 화면 + 헤더 아바타 진입(프로필) + 풀스크린(온보딩·퀴즈 응시·증명서 미리보기) + 사이드바 토글 off 라우트(멘토링·마일리지·동료평가).
> 결과 표기: 각 표의 **결과** 칸에 `✓`(정상) / `✗`(버그) / `△`(애매·확인필요) 기입. `✗`·`△`는 맨 아래 **이슈 로그**에 상세를 남긴다.

---

## 0. 세팅 가이드 (QA 시작 전)

1. `pnpm dev` 실행 → 브라우저로 접속.
2. `/login` → **"수강생" 빠른 로그인** 버튼 클릭 → 폼 자동 입력(제출은 직접) → 로그인.
   - mock은 이메일 prefix로 역할 판별: `student@…` 외 일반 이메일 → STUDENT.
3. **상태 초기화 팁** (개발자도구 → Application → Local Storage):
   - `lms-auth` 삭제 → 로그아웃 상태로 리셋(가드·로그인 흐름 재현).
   - `lms-onboarded:{userId}` 삭제 → 온보딩 마법사 첫 진입부터 재현.
   - `lms:test-fab-pos` → 🧪 테스트 버튼 위치(무시 가능).
4. **🧪 TestModeFab**(우하단 플로팅 버튼): 일부 화면에서 상태 분기를 시뮬레이션한다. 현재 확인된 위치 — **멘토링**(멘토 배정 전/후·일정 경과), **프로젝트 워크스페이스**(흐름 네비), **증명서**(인증 요청 흐름·미리보기). 그 외 화면은 대부분 없음.
5. **CERT_V2 플래그**: `src/features/student/certificate/config.ts`의 `CERT_V2 = true`. `false`로 바꾸면 증명서 **AI 분석 탭**이 사라진다(v2 영역 점검 시 토글).

> ⚠️ 화면에 보이는 이름·기수·학번 등은 **mock 고정값**이라 아래 페르소나(박준석/SKN 22기)와 다르게 보일 수 있다(예: 증명서 mock은 다른 이름). **데이터 정합성보다 기능·흐름·상태·검증 동작**을 중심으로 본다.

## 12. 사이드바 토글 off 라우트 (직접 URL 접근)

> 사이드바엔 없지만 라우트는 살아있다. **노출/차단 의도가 맞는지** 함께 확인(직접 URL로 들어가 정상 동작하는지, 아니면 막아야 하는지 판단 메모).

### 12.1 멘토링(V2 변형 포함) — `/student/mentoring`

| 시나리오                            | 기대 결과                                           | 결과 |
| ----------------------------------- | --------------------------------------------------- | ---- |
| 직접 URL 진입                       | 정상 렌더(사이드바엔 없음) — 의도 확인              |      |
| 🧪 멘토 배정 전(`?state=no-mentor`) | 히어로 대기 안내·통계 0·요청 폼 비활성·정책만       |      |
| 🧪 배정 후                          | 통계·요청 폼·이력 노출                              |      |
| 새 요청 제출(날짜/시간/장소 필수)   | activeRequest 생성 + "요청이 제출되었습니다" 토스트 |      |
| 진행 슬롯 점유 중 새 요청           | 폼 비활성(1개만 허용)                               |      |
| 조정 제안 수락/거절·취소            | 모달 → 상태 전환 + 토스트                           |      |
| 🧪 일정 경과                        | 진행 요청/예약 → 이력 이동                          |      |

### 12.2 마일리지 — `/student/mileage`, `/products`, `/requests`, `/history`

| 시나리오                     | 기대 결과                                          | 결과 |
| ---------------------------- | -------------------------------------------------- | ---- |
| 내 마일리지 진입             | 잔액 히어로 + KPI + 최근 내역 + 상품 + 타입별 한도 |      |
| 상품 신청 직접 입력          | 링크 URL 유효성(http/https)·가격 숫자 검증         |      |
| 요청 제출(링크+가격 필수)    | `/student/mileage/requests` 이동                   |      |
| 구매 요청 상태(카탈로그 4종) | 확인 모달 / 완료 / 반려 / 한도 초과(제출 비활성)   |      |
| 사용 내역                    | 필터·기간·검색·페이지네이션 동작                   |      |

### 12.3 동료 평가 — `/student/peer-evaluations`, `/peer-tag`, `/peer-reputation`

| 5축 평가: 별점(1~5)·추천도·코멘트(200자) | 입력·평균 실시간 계산                                |      |
| 임시 저장 / 다음 동료                    | 데이터 유지 / 저장 후 이동                           |      |
